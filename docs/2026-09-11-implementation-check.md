## 验证证据

1. 14 项单元测试通过，涵盖种植扣费/占用/越界/小数坐标/冷却、资源不足、铲除、生产/重复采集、暂停、分行伤害、爆破、一次救场、胜负、固定步长、贴身射击、存档容错和解锁。部分断言在同一用例中。
2. TypeScript 检查与生产构建通过。Vite 提示引擎主包较大：压缩前约 1.42 MB，gzip 约 384 KB；没有构建错误。
3. 浏览器实际操作验证主菜单、开始、选卡、种植、采集、冷却、铲除、重开、玩法说明、暂停、继续和选卡后空格暂停；检查了窄预览窗口和 1440 × 900 桌面布局，没有记录到应用错误或警告。
4. 独立审查使用正常资源和逐步种植策略在规则模型中跑通三关，不等同于三关全部完成人工实玩。
5. 已修复审查发现的贴身补种射手打空、按钮焦点影响空格暂停、缺少装甲/死亡音效。复审确认闭环。
6. 18 个 WAV 解码、峰值和循环接缝检查通过，没有声称完成人工听感验收。
7. 用户反馈打不开后，确认本机 HTTP 200，旧临时预览标签已关闭；重新打开并保留交付标签。终止本轮旧开发服务后，独立启动入口冷启动成功，新服务进程为 1188，页面重新显示主菜单。从项目外执行入口复用服务也通过。

## 补充美术

内置 ImageGen 分别生成三株植物，本次均具有有效 alpha。Pillow 保留透明度并整理为 256 × 256 帧，脚底基准 y=235。源图：`art-source/characters/{glow,wall,bomb}-idle-v1.png`；发行图：`public/assets/`。

共同提示词：原创庭院塔防精灵，暖色手绘绘本、水粉纹理、棕色描边、深青绿叶子、琥珀阳光配色，三分之四侧面略朝右，完整单体居中留空，无文字和地面阴影，真正透明背景。

- 灯铃花：金黄发光下垂铃形花头、温和笑脸、弯曲茎与两片大叶。
- 栗壳卫士：栗色圆身体、苔绿带刺厚壳、坚定眼神与底部叶片。
- 火椒果：胖圆红橙椒果、卷曲引线形花梗、小金色火星、顽皮面孔与底叶。

## 实现取舍

Phaser 管理战斗画面，原生 HTML 管理文字和菜单。新植物采用静态图加摆动；装甲和快速敌人复用行走动画并增加帽子/围巾标记，尚无独立分层动画。
