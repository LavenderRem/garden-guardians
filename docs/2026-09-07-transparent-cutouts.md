## 实际处理方式

使用现有 Python 环境中的 Pillow 和 NumPy。根据 RGB 棋盘格的高亮、低色差特征，从部件外缘进行连通填充，只移除可连通到背景的区域，保留眼睛等闭合内部高光；花盆绳环内部的背景单独指定种子点处理。

随后针对轮廓附近的两像素范围，依据相邻内部颜色和背景颜色估计透明度，减少原棋盘格在边缘形成的浅色残留。保留抗锯齿所需的半透明边缘。该步骤为本地图片后处理，本轮没有调用新的 ImageGen 生成，也没有使用 CLI 图像生成接口。

处理脚本位于工作区外的 `C:/Users/180841/.codex/tmp/game-test-cutouts/process_cutouts.py`，用于复现素材处理；游戏工程没有新增程序文件。
