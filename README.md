# 庭院守卫

原创手绘风格的浏览器庭院塔防游戏，已完成三关可玩首版。

## 打开游戏

在资源管理器中进入 `D:\AI\Projects\game-test`，双击 **启动游戏.cmd**。入口会自动启动本机服务并用默认浏览器打开游戏；已有服务时直接复用。

当前试玩地址：<http://127.0.0.1:5173/>。如果端口被其他程序占用，启动入口会尝试 5174–5183，并显示实际地址。

请使用启动入口或网址；直接双击 `index.html` 无法运行开发工程。建议在桌面浏览器最大化窗口中试玩。关闭页面不退出后台服务，再次双击入口即可返回。

## 玩法

- 选择卡片后点击草坪种植；点击金色光露增加 25 资源。
- 灯铃花持续生产资源；种荚射手攻击本行；栗壳卫士阻挡敌人；火椒果在 1 秒后清理周围 3 × 3 格。
- 每行花车只救场一次。击退全部来客获胜，花车用完后再次被突破则失败。
- 通关自动解锁下一关；进度和音量保存在当前浏览器，不保存正在进行的战斗。

快捷键：`1–4` 选卡，`5` 铲除，`E` 收集光露，`空格` / `Esc` 暂停。

## 开发

技术栈：Phaser 4.2.1、TypeScript 5.9、Vite 7、Vitest 3；依赖版本由 `pnpm-lock.yaml` 锁定。

```text
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
```

本机启动入口优先使用开发环境自带的 Node.js，找不到时使用系统 Node.js。其他电脑需要先安装 Node.js 和项目依赖。

| 路径 | 内容 |
| --- | --- |
| `src/game/` | 关卡、固定步长战斗模拟、画面与规则测试 |
| `src/main.ts`、`src/style.css` | 菜单、卡片、说明、暂停和结算 |
| `src/save.ts`、`src/audio.ts` | 本地进度和声音 |
| `public/assets/` | 游戏加载的美术、动画和音频 |
| `art-source/` | 原创源图和动作样片 |
| `scripts/` | 素材整理、声音合成和启动入口 |
| `docs/` | 规划与验收记录 |

运行游戏不需要生成服务账号或密钥。

## 当前范围

四种植物、三种敌人、三关、胜负、冷却、铲除、救场、暂停、重开、音量与本地解锁。已有原创角色动画和 18 个 WAV（2 段配乐、2 段结算短乐、14 个音效）。

手机小屏目前仅整体缩放，没有专门触控布局。规划中的独立片头视频、实机宣传视频、原生安装包与线上发布尚未完成；现有 GIF 是动作素材样片。
